# NOVA WORLD — Prototype 0.1

スマホ対応を優先した、無料で試せるブラウザ3D仮想社会の試作品です。

## この試作品でできること
- 3Dの街を歩く（スマホは左下の操作パッド、PCはWASD/矢印キー）
- 住人3人と会話する（会話は試作版の定型ロジック。外部AI APIは使いません）
- 日本語の文章から家具・街灯・植物・箱・クリスタルなどを生成
- 作品をマイ作品に保存し、テスト用マーケットに出品・購入
- 進行状況を同じブラウザの localStorage に保存

## 制限
- 文章からの作品生成は、入力語を判定して既存の3Dパーツを組み合わせる方式です。生成AIによる新規3Dモデル作成ではありません。
- 会話はAI APIではなく、キーワードに応じた試作ロジックです。
- データ保存はその端末・ブラウザ内のみ。アカウント、サーバー保存、他ユーザーとの同期はありません。
- ゲーム内通貨はテスト用で、現実のお金への換金・決済はありません。
- Three.js を CDN から読み込むため、初回表示時にインターネット接続が必要です。

## いちばん簡単な公開方法
1. GitHub にログインし、新しい **Public** リポジトリを作成（例: `nova-world-mvp`）。
2. この ZIP を展開し、`index.html` と `README.md` をリポジトリの一番上にアップロード。
3. リポジトリの **Settings → Pages** を開く。
4. **Deploy from a branch** を選び、Branch は `main`、Folder は `/(root)` を指定して保存。
5. 数分待ち、Pages に表示される URL をスマホで開く。

注意: GitHub Pages は静的な試作品の公開・検証用です。公開前に現在の GitHub Pages 利用条件を確認してください。商用サービスとして運営する段階では、商用利用条件に合うホスティング先とバックエンドを選びます。
